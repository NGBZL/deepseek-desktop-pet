# 小D · DeepSeek 桌面宠物

一只基于 **PyQt5** + **DeepSeek API** 的 Windows 桌面宠物。她会自己在屏幕上散步、随机找你聊天，还能搜索网页和“看”你的屏幕截图。

## ✨ 功能

- 🚶 **自主行为**：随机散步、转身、停下，并自动在屏幕边缘反弹
- 💬 **AI 聊天**：基于 DeepSeek 的拟人化对话，带自定义气泡 UI 和淡入淡出动画
- 🔍 **搜索工具**：AI 可调用工具直接打开浏览器搜索
- 📷 **识图工具**：AI 可截取屏幕并分析内容（需要多模态模型）
- 🛡️ **三层审核**：每个工具调用先经安全审核员（安全 / 意图对齐 / 路径优化）再执行
- 🖱️ **交互**：左键拖动、双击聊天、点击气泡回复、右键菜单
- 🎨 **无边框窗口 + 圆角气泡 + 阴影**，支持透明背景

## 📦 安装

```bash
pip install -r requirements.txt
```

需要 Python 3.8+。`PyQt5`、`requests`、`Pillow` 三个依赖。

## 🔑 配置 API Key（重要）

密钥通过环境变量提供，先去 <https://platform.deepseek.com/> 申请一个。

**Windows (PowerShell)**

```powershell
$env:DEEPSEEK_API_KEY = "sk-你的密钥"
python pet.py
```

**macOS / Linux**

```bash
export DEEPSEEK_API_KEY="sk-你的密钥"
python pet.py
```

也可以复制 `.env.example` 为 `.env` 自行管理（`.env` 已被 `.gitignore` 忽略）。

> ⚠️ 如果未设置该变量，程序启动时会直接提示并退出。

### 可选的 Qt 插件路径

如果你用的是便携版 Python 且遇到 Qt 插件加载失败，可以额外设置：

```powershell
$env:QT_QPA_PLATFORM_PLUGIN_PATH = "你的\PyQt5\Qt5\plugins"
```

## 🛡️ 审核 AI

除了陪你聊天的主模型，程序里还跑着**第二个 AI 角色：审核员**（代码里的 `AUDITOR_PROMPT`）。它不是给你看的，是给小D 的“行为守门人”。

小D 每次想调用工具（目前是搜索、截图）时，**不会直接执行**，而是先把「你的原问题 + 小D 打算执行的具体指令」一起交给审核员，由它独立判断后再放行。

审核分三层：

| 层次 | 检查内容 | 不通过时 |
| --- | --- | --- |
| 第 1 层 · 安全检查 | 是否涉及危险操作（删除文件、改系统配置、访问敏感数据等） | 直接拒绝 |
| 第 2 层 · 意图对齐 | 这条指令是否符合你的真实意图、有没有跑偏 | 偏离则拒绝并给出建议 |
| 第 3 层 · 路径优化 | 这是不是达成你需求最合理的路径 | 指出更优路径 |

审核员按固定格式给出结论：**决策**（✅ 批准 / ⚠️ 修改 / ❌ 拒绝）+ 三个分项说明 + 一句话总结。

**只有结论里出现「✅ 批准」时，工具才会真正执行**；否则小D 会把审核意见显示在气泡里，并把结果回传给主模型继续对话。这样即使主模型被诱导去做危险操作，也会被这一层拦住。

审核用的模型是 `deepseek-chat`，`temperature` 与主对话一致（0.8）。想调整审查尺度，直接改 `pet.py` 里的 `AUDITOR_PROMPT` 即可。

## ⚙️ 主要参数

可在 `pet.py` 顶部的“配置”区域调整：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `BUBBLE_DURATION` | `30000` | 气泡自动消失时间（毫秒） |
| `WINDOW_SIZE` | `150` | 宠物窗口边长（像素） |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | API 地址 |

移动速度、动画帧间隔等参数在 `DesktopPet.__init__` 中：`self.speed`、`self.step_interval`。
